Linux Security Monitor

A lightweight Python-based Linux security tool for log analysis and file integrity monitoring (FIM).

The project detects suspicious authentication activity, monitors files for unauthorized changes, and stores security events in centralized JSON reports.

🔐 Features
1. Linux Log Analyzer
Detects failed SSH login attempts
Detects successful SSH logins
Extracts source IP addresses
Counts failed attempts by IP
Assigns severity levels
Generates JSON security reports
Supports real-time log monitoring
2. File Integrity Monitoring (FIM)
Uses SHA-256 hashing
Creates a file baseline
Detects modified files
Detects deleted files
Detects newly added files
Supports directory-wide monitoring
Assigns severity levels
Generates JSON reports
3. Central Security Event Collector

Security events generated by the Log Analyzer and FIM are stored in a central JSON file:

reports/security_events.json

This provides a simple centralized view of security events.

🚀 Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/Linux_security_monitor.git

Move into the project directory:

cd Linux_security_monitor

No external Python packages are currently required.

🛡️ Log Analyzer

The Log Analyzer processes SSH authentication logs and identifies suspicious login activity.

Run the analyzer

From the project root:

python log_analyzer/analyzer.py --log log_analyzer/sample.log

📁 File Integrity Monitoring

The FIM module creates a baseline of files using SHA-256 hashes.

It can detect:

Modified files
Deleted files
New files
Create a baseline

From the project root:

cd file_integrity

Then:

python fim.py --path security_files --init
Check file integrity
python fim.py --path security_files --check

Example:

========================================
        FILE INTEGRITY SCAN
========================================

New files       : 1

[+] Security report saved:
    reports/fim_report.json
📊 Central Security Events

Both security modules send detected events to:

reports/security_events.json

Example event:

{
    "timestamp": "2026-10-01 12:00:00",
    "source": "LOG_ANALYZER",
    "event": "FAILED SSH LOGIN",
    "target": "192.168.1.50",
    "severity": "HIGH"
}

This demonstrates a basic security-event collection workflow similar to the concept of centralized security monitoring.

👀 Real-Time Log Monitoring

The Log Analyzer also supports real-time monitoring.

python log_analyzer/analyzer.py --log log_analyzer/sample.log --watch

The program continuously checks the log file for new authentication events.

Press:

CTRL + C

to stop monitoring.
